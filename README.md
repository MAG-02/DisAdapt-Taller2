## Diseño

Primero planteamos la estructura mediante **wireframes en baja** y después pasamos el diseño a código.

Buscamos mantener una estética relacionada con los videojuegos usando:

- Fondos oscuros.
- Detalles y acentos en azul claro.
- Imágenes de los videojuegos.
- Efectos de transparencia y hover.

## Desarrollo

El proyecto fue realizado con **React + Vite** y utilizamos **Tailwind CSS** para construir los estilos y adaptar la página a diferentes dispositivos.

Cada sección se trabajó como un componente independiente para que fuera más fácil organizar y modificar el proyecto.

Ademas primero comenzamos usando a gemini y ya despues de tener la estructura base, nos pasamos a copilot que esta integrado al Visual Code para pulir los detalles finales.
